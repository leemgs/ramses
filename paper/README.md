# Paper sources

This directory is the self-contained LaTeX paper workspace:

- `main.tex`, `IEEEtran.cls`, `IEEEtranDOI.bst`, and `reference-data.bib` are
  the document entry point and local LaTeX/BibTeX dependencies.
- `section/` contains the manuscript sections.
- `figures/` contains paper figures, including figures generated by the code
  pipeline.
- `tables/` contains table wrappers and generated table bodies.

Build the paper from this directory so all relative LaTeX paths resolve:

```sh
cd paper
latexmk -pdf main.tex
```

The executable artifact and its input data live in the sibling `../code/`
directory. Run its generators from the repository root as documented in
`../code/README.md`.
